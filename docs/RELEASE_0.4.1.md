# ImmersiveGroups 0.4.1

This release focuses on making the scene controls and library easier to use on phones.

- The background picker shows whether loading a matching background on chat load is enabled, and offers a shortcut to its settings. Native chat background locks still take priority.
- Outfit cards start compact on smaller screens. Expand a card to edit its details, upload sprites, or manage expressions.
- If a library edit cannot be saved, the draft is kept while the page remains open, including when the library is closed and reopened. Retry or discard it from the card. Reloading the page clears unsaved drafts.
- Successful transfer results are compact on small screens and can be expanded. Errors and partial-result warnings stay visible.
- Touch controls have more room where this does not override the scene's adjustable control sizes.

The transfer format and import conflict-review rules are unchanged. Check the changes with your own theme and devices, particularly mobile browsers and keyboards.
