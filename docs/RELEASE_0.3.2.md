## 0.3.2 — Media and transfer improvements

- Replaced the scene background/image dropdowns with a **compact visual picker**, featuring thumbnails, compact lists, search, current-selection highlights and keyboard navigation.
- Added **Linked, Starred and All background pools**, current-chat character/group filters, a compact model-change lock and useful empty states.
- Kept the picker header and actions visible while the asset list scrolls; shortened labels and corrected button wrapping on PC and mobile.
- Reorganized import/export into **Outfits, Character, Extra, Gallery and Settings**, with independent choices for entries, descriptions, library order, locks, colors and image files.
- Added **PNG/JSON character-card selection** and a per-background inclusion checklist. Existing 0.3.1 bundles remain importable.
- Collapsed empty paragraphs and line breaks left by hidden outfit/background commands, including commands before, between or after narration. Hiding remains reversible and preserves native HTML and stored chat messages.

Existing sprite ZIP imports are unchanged. README.md is delivered separately from extension packages when requested.
