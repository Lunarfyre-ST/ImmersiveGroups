## 0.3.1 — Character transfers

- Added a dedicated **Import / export window** in the Library and extension settings, alongside the existing sprite ZIP imports.
- Added named ZIP bundles with selectable **outfits, heights, PC/mobile fine tuning, button colors, PNG character cards, backgrounds, named group presets, gallery assignments and extension preferences**.
- Added optional sprite/background/gallery image files, a current-chat selection and an all-library settings preset.
- Added validated import previews, explicit character mappings, editable sprite roots and keep/update policies for matching metadata.
- Preserved complete group membership and bindings during remapping; incomplete relationships are skipped with a report.
- Kept existing character cards and image files, isolated failed uploads from settings changes, and excluded chat history and API connection details from portable settings.
- Added archive limits, checksums and support for local-network HTTP browsers. Imported automation preferences remain off until enabled.

See [Character and settings transfers](TRANSFERS.md) for setup and limits.

This build focuses on character/settings transfers. Time-of-day filtering and expression-count sorting from the 0.3.1 idea list are not included yet.
