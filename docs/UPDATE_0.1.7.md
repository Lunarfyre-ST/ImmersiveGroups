# ImmersiveGroups 0.1.7 — Scene tools and image menu

Copy the ZIP’s ImmersiveGroups contents over the existing extension files and reload SillyTavern. The root README.md is omitted to preserve your repository README. Existing automation remains opt-in.

- Scene tuning stays fixed in the viewport while its sliders move the chat window or character controls. Sliders still update the scene live. The panel scrolls when it needs more room and clamps to the visible viewport when the screen or keyboard changes size.
- Fit calibration uses a −20% to +20% slider in both the main settings and Scene tuning, with 0% as the default. The number field still accepts larger adjustments (−99% to +500%). Existing saved scaling values are retained.
- Outfit catalogs remain global per character avatar across solo chats and groups. Native outfit overrides are captured even for characters whose sprite is not currently loaded; observed, imported and discovered folders also enter the shared folder memory. Discovery retries legacy “done” flags, missing catalog entries and changed folder roots. Hidden/removed entries stay respected. This stores settings on the current SillyTavern account/server; it cannot merge unsaved changes from another browser session.
- Backgrounds and Quick Image Send share one scene button. The menu has Backgrounds and Send image pages, with subtle color accents, image search, gallery filtering, previews and direct library links. Background selection can be disabled while the image page stays available.
- Gallery → Gallery shortcuts → Quick Image Send chooses the scene menu (default), floating icon, both or hidden. Previous floating icon dimensions and positioning values are retained. If scene controls are off, the default scene-menu placement falls back to the floating icon so image sending remains accessible.
- Send image sends an explicit narrator image message through SillyTavern’s existing send button. It is disabled while a draft is present; Insert command appends the command to your draft instead. Neither action asks the model to generate a reply automatically.
- Image details always show character and group binding controls. Selecting a binding switches availability to Bound characters / groups. Character bindings follow characters into groups; the all-required option requires every selected character. An explicit group binding is an alternative match. Descriptions and binding rules continue to feed the optional Gallery prompt.

Validation: syntax/import checks, all 29 unit tests, and browser integration against mocked SillyTavern APIs. Browser coverage includes real slider dragging, persistent outfit data across chat changes and a fresh runtime, image availability/bindings, draft protection, mobile bounds, swipe image rendering and the existing scene automation/lock checks. Real model and API behavior still require testing in SillyTavern.
