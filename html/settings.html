ImmersiveGroups
Character scenes, sprites & galleries · Combined project based on Prome and LocalImage.

Start with character controls and outfits. Use Sprites for scale and dimming, Chat layout for space, and Gallery for images. Changes save automatically.

Profile settings have a PC / Mobile badge. Other settings apply to both. Selecting an edit profile does not switch the live layout; use “Use layout” to preview it.

Placement & alignment

Names above creates compact columns. Each control can be placed independently; hidden buttons keep their settings.
Sheld controls
Size & idle appearance Hovered, focused and open controls return to full opacity. Set opacity to 100% to turn fading off. Manual outfit selections apply immediately.
Outfit library
Rename display labels, show/hide and reorder outfits, add custom folder names, or import names from your character’s sprite folder. Existing Quick Reply outfit changes are remembered as they appear.

The outfit library includes per-character button backgrounds, Speak colors and text colors, plus per-outfit font colors and scene descriptions. Descriptions are saved for future context injection; no automatic model changes run yet.

Uses your active group members and current outfit folders. Character Expressions must be enabled.
Sprite spacing
Smaller values bring characters closer together. Saved manual positions take precedence.
Character heights

The tallest active character is the reference. Set heights in centimeters, adjust Fit calibration above until that character fits the screen, then fine tune individual sprites below. Changing a value enables height scaling.

Height is shared across PC and mobile. Fine tuning and Fit calibration are saved separately for each profile. Previous height settings are kept in a migration backup.
Speaker dimming
0% keeps a sprite fully lit; 100% makes it black. Order follows distinct character speakers and ignores user/system messages. Shadow opacity remains separate.
Extra replies scroll inside the bar instead of shrinking the chat. Set rows to 0 to hide the inline bar. The popup is unaffected.
Default: 1000 px. Mobile rows apply when the visible window height is at or below this value.
Automatic (default) Default: 0 = automatic (original SillyTavern/theme height). Set 1–100 for a percentage of the visible window. Applies in VN mode.

Scene backgrounds

Browse the full background list and star your favorites. The normal selector shows only starred entries. Scene descriptions are saved with each background for future context injection. Optional character bindings filter favorites by character; they do not change backgrounds automatically. Native background locks are respected.

Work in progress — planned features

Outfit, background and image descriptions are being prepared for scene context. The automation modes below are planned; choosing outfits and backgrounds still uses manual controls. Gallery’s existing optional image prompt is configured in its own tab.

Automation modes

Prompt Mode
Generate automation commands at the end of the RP message. Intended to offer strong context, speed and lower cost, with the highest risk of malformed or incorrect commands.
API Mode
Make a second call just for automation, using the main API, another connection profile, or a local / OpenAI-compatible server.

Prompt character scope

All active characters
Largest prompt, with support for changing several outfits at once. A stable prompt may improve speed and cost when the provider supports effective caching.
Active character only
Fewest prompt tokens overall. The prompt changes with each speaker, which may reduce cache reuse. A smaller character list may reduce character confusion and unintended changes.

Actual cost, speed, caching and reliability depend on the model, provider and implementation. No additional API call is made by this roadmap.
