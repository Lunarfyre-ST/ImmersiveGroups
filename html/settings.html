Automation roadmap

Available now

Prompt mode appends validated outfit and background commands to the RP reply. All active characters and speaking-character-only scopes are supported, including outfit locks and background locks. Separate API analysis can run manually or automatically after replies using the main API, a connection profile or a custom endpoint.

Work in progress — planned features

A movable Chat Completions Prompt Manager entry and coordinated Gallery image selection are planned. Automatic API analysis is available as an opt-in and runs once after a completed group round.

All active characters supports group-wide outfit changes and offers a larger, more stable catalog; speaking-character-only context uses fewer tokens but changes with each speaker. Actual caching, cost and speed depend on your provider.
